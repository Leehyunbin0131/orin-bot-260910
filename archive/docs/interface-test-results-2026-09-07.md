각 구동 단계는 1초 목표이며 통신 처리 시간에 따른 소폭 차이가 있습니다. 시험 종료 시 양쪽 토크 OFF와 목표 속도 0을 확인했습니다. 기존 운영 모드도 복구했습니다(왼쪽 3, 오른쪽 1). 센서 재시험 후 상태 조회에서도 양쪽 토크 OFF가 확인되었습니다.

사용자가 고속에서 모터가 동작하지 않는다고 알려주어 시험 속도를 올리지 않았고, 테스트 CLI도 원시값 15를 상한으로 제한했습니다. 바닥에 내려놓은 주행 방향·추종 성능은 이번 시험에 포함하지 않았습니다.

## 수정한 실행 구성

기존 배포판 rplidar_ros 드라이버는 장치 건강 상태 OK를 받은 뒤 메모리 오류로 종료되었습니다. 제조사 sllidar_ros2를 소스 빌드하여 교체한 뒤 스캔과 정상 종료를 확인했습니다. 커밋은 `34300099fadfc772965962dec837bf436706188f`입니다.

현재 ARM64 RealSense 빌드는 포인트클라우드 파라미터를 `pointcloud__neon_.enable`로 노출합니다. 이를 활성화한 뒤 실제 포인트클라우드 수신을 확인했습니다.

## 남은 IMU 문제

현재 커널은 `6.8.12-1021-tegra`이며 `/proc/config.gz`에 `# CONFIG_HID_SENSOR_HUB is not set`가 있습니다. 관련 HID 센서 모듈 3개도 발견되지 않았고, 카메라 HID 인터페이스는 `hid-generic`에 연결되어 IIO 장치가 없습니다. RealSense 로그는 `No HID info provided, IMU is disabled`를 보고합니다.

현재 SDK의 native backend에서 IMU를 사용하려면 HID 센서 드라이버 지원을 추가하거나 RSUSB backend를 별도로 준비해야 합니다. 이번 하드웨어 점검에서는 커널·펌웨어를 변경하지 않았습니다. 카메라는 USB 2.1(480Mbps) 경로로 연결되어 있으며, 위 영상 수신률은 이 연결에서 측정한 값입니다.
